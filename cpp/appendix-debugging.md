# 附录 2：调试工具箱

调试（debugging）的目标不只是“让程序跑通”，还要知道**错误为什么产生**。

## 1. 编译、运行与调试不是一回事

- **compile**：将源代码编译为目标代码。
- **link**：把所需目标代码和库连接成可执行程序。
- **run**：启动运行程序。
- **debug**：通过断点和变量观察执行过程。

## 2. 常用术语

| 英文 | 中文 | 用途 |
| --- | --- | --- |
| breakpoint | 断点 | 让程序停在某一行 |
| step over | 单步越过 | 执行当前语句而不进入函数内部 |
| step into | 单步进入 | 进入被调用函数 |
| call stack | 调用栈 | 查看当前函数调用关系 |
| watch | 监视表达式 | 持续观察一个值 |

## 3. 调试顺序

1. 用最小输入重现。
2. 找到最早偏离预期的位置。
3. 查看变量类型和当前值。
4. 修复后重新运行测试。
5. 将错误成因记入笔记。

::: warning 小心未定义行为
数组越界、访问悬空指针等问题，可能并不总是立刻崩溃；“这一次运行没报错”不代表正确。
:::
