# 学习与写作指南

这部分专门回答两个问题：**怎么把知识记清楚**，以及 **怎么长期维护自己的 StarsunNotes**。

## 快速入口

- [Markdown 写作规范](./markdown.md)：标题、代码块、图片、表格与术语。
- [网站管理与维护](./website.md)：文件结构、启动命令、备份和构建检查。
- [学习迭代日志](../journal/index.md)：每次学习结束时记录真实进度。

## 建议的学习笔记结构

一篇真正有用的笔记至少回答四个问题：

1. 这是什么？
2. 为什么需要它？
3. 最简单的例子是什么？
4. 我犯过什么错误，怎么改正的？

::: tip 语言学习习惯
遇到 `cout`、`RAII`、`CMake` 这样的英文术语，优先补上英文来源、缩写全称和中文解释，避免只背“它的作用”。
:::

## 公开与隐私

本地 Markdown 文件不会因为运行 VitePress 就自动上传到互联网。**只有你主动部署、共享或上传时，内容才可能被别人访问。**

如果将来要公开网站，请先检查是否包含个人信息、账号、私人链接或其他保密材料。
